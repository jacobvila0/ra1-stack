# ra1-stack de Jacob

Página web sencilla de bienvenida para el proyecto **ra1-stack de Jacob**.

## Contenido

- `index.html`: página principal con los estilos incluidos en el propio archivo.

## Cómo verla

Abre `index.html` directamente en un navegador web.

También puedes servir la carpeta con un servidor local. Por ejemplo, con Python:

```bash
python -m http.server 8000
```

Después, visita `http://localhost:8000` en el navegador.

## Tecnologías

- HTML5
- CSS3
